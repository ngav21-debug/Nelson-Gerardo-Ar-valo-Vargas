Antes de usar el resultado

  • El OCR comete errores, sobre todo en manuscritos, sellos, tablas y fotocopias tenues. Coteja con el original toda cita textual que vaya a un auto o a un escrito.
  • El PDF/A se arma con la estructura de la parte 2, nivel B (metadatos XMP, perfil sRGB incrustado, sin cifrado ni transparencias). Los archivos de prueba pasaron la validación de veraPDF para PDF/A-2b, pero si el documento va a un repositorio que exige conformidad, valida cada archivo con veraPDF.
  • Las páginas se guardan como imagen más una capa de texto invisible. Las firmas digitales del original no se conservan.
  • Un expediente de cientos de páginas puede tardar varios minutos. Deja la pestaña abierta mientras trabaja.
