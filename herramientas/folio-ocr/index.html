Folio OCR

Lee PDF escaneados o nativos, reconoce el texto página por página y entrega el documento en Markdown, Word y PDF/A. Si lo pides, prepara además una versión anonimizada que conserva el formato de las páginas originales, con los datos personales tachados sobre la imagen.

Todo corre en este navegador. Los PDF no se suben a ningún servidor.
Lectura
Para Markdown y Word. Las páginas digitales conservan su texto exacto; las escaneadas pasan por OCR.
Anonimización
Detecta los datos, te deja revisarlos y genera Markdown, Word y PDF/A con el mismo formato de páginas del original.

Antes de usar el resultado

  • El OCR comete errores, sobre todo en manuscritos, sellos, tablas y fotocopias tenues. Coteja con el original toda cita textual que vaya a un auto o a un escrito.
  • La anonimización busca patrones y nombres en el texto reconocido. No tacha firmas manuscritas, fotos, huellas ni datos que el OCR leyó mal. Revisa la tabla y la vista previa de cada página antes de entregar un documento.
  • El tachado se hace sobre la imagen de la página y el texto original no queda debajo. El PDF anonimizado no se puede “destachar”.
  • La tabla de equivalencias contiene los datos reales. Guárdala con la misma reserva del expediente y nunca la anexes a la versión anonimizada.
  • Los PDF salen en PDF/A-2b (metadatos XMP, perfil sRGB incrustado, sin cifrado). Los archivos de prueba pasaron veraPDF, pero si el documento va a un repositorio que exige conformidad, valida cada archivo.
  • Las páginas se guardan como imagen con una capa de texto invisible. Las firmas digitales del original no se conservan.
